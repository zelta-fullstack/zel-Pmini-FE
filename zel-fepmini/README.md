# Bandung Tourism Destinations - Frontend

Aplikasi web frontend untuk menampilkan destinasi wisata di Bandung. Dibangun dengan React 19, Vite, dan React Router, aplikasi ini terhubung dengan REST API backend untuk menyajikan informasi wisata yang lengkap dan interaktif.

## 🎯 Tentang Aplikasi

**Bandung Tourism Destinations** adalah platform web untuk membantu wisatawan menemukan dan menjelajahi tempat-tempat wisata menarik di Bandung. Aplikasi ini menampilkan 15 destinasi wisata populer dengan informasi lengkap termasuk lokasi, jam operasional, dan harga tiket.

Histori pengembangan: Aplikasi ini berhasil dikembangkan pada 5 November 2024 sebagai MVP Phase 1 dengan semua fitur integration testing passed dan production ready!
